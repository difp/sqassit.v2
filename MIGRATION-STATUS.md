# Migration status

Reference: SQASSIT `736a779f59d9e13d7e3a0f0401d6dd1c642cfada`, imported under `legacy/`.

## Implemented in Rust

- Telegram Mini App initData and scoped token validation, with fixed vectors generated by the reference implementation.
- Stable anonymous identities and an in-memory sliding-window rate limiter.
- SQLite schema initialization and legacy column migrations, including notification expiry and onboarding backfills. SQLite uses WAL, a busy timeout, foreign keys, and the `search_norm` function.
- Atomic training booking, approval, rejection, cancellation and FIFO promotion, including simultaneous requests for the last place.
- Experimental Axum HTTP shell renders the legacy templates and serves static files. Readiness deliberately returns 503 while the API and bot are incomplete.

## Baseline and verification

On 2026-11-11 the Python reference tests ran in an isolated Python 3.12 environment: **299 passed, 2 skipped**, with coverage options disabled. The TestClient integration test stalled inside the sandbox and passed outside it. Rust unit tests and Clippy run through the root `Cargo.toml`; CI executes formatting, Clippy and tests.

## Still required

This is **not a runnable Rust replacement** yet. HTTP routes/templates, the rest of the data access and business logic, bot, notifications/scheduler, operational integration, cross-implementation contract tests and deployment/rollback validation remain to be implemented. Do not deploy this crate in place of the Python application.
